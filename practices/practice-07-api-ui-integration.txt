PRACTICA 07 - INTEGRACION API + UI CON PLAYWRIGHT

OBJETIVO

Combinar peticiones HTTP y acciones de interfaz dentro de una misma prueba Playwright.

Flujo de la practica:

API -> preparar
UI  -> actuar
API -> verificar
API -> limpiar


============================================================
1. PREPARAR EL LABORATORIO
============================================================

$REPO = "C:\Users\student\Desktop\test-automation-playwright-screenplay-copilot"
$TEST_AUTOMATION = $REPO + "\test-automation"
$INSTRUCTOR = $TEST_AUTOMATION + "\practices\day-03\practice-07\api-ui-integration-instructor.spec.ts"

Set-Location $REPO


============================================================
2. LEVANTAR LA APLICACION
============================================================

docker compose up -d

docker compose ps

Debes observar los servicios:

frontend
backend
postgres


============================================================
3. VALIDAR QUE LA API RESPONDE
============================================================

curl.exe -i http://localhost:8080/

Resultado esperado:

HTTP/1.1 200 OK

Body esperado:

{"status":"running"}


============================================================
4. CONSULTAR LAS TAREAS
============================================================

curl.exe -i http://localhost:8080/api/tasks

Resultado esperado:

HTTP/1.1 200 OK

Si no existen tareas:

[]


============================================================
5. CREAR UNA TAREA DIRECTAMENTE POR API
============================================================

$REQUEST_FILE = $REPO + "\request-p7.json"

Set-Content -Path $REQUEST_FILE -Encoding ASCII -Value '{"title":"P7 tarea manual"}'

$CREATE_RESPONSE = curl.exe -sS -X POST -H "Content-Type: application/json" --data-binary "@$REQUEST_FILE" http://localhost:8080/api/tasks

$CREATE_RESPONSE

Resultado similar a:

{"id":1,"title":"P7 tarea manual","completed":false}

Convierte la respuesta a un objeto PowerShell:

$CREATED_TASK = $CREATE_RESPONSE | ConvertFrom-Json

Obtiene el id real:

$TASK_ID = $CREATED_TASK.id

Write-Host ("Task id: " + $TASK_ID)


============================================================
6. CONSULTAR LA TAREA POR ID
============================================================

curl.exe -i ("http://localhost:8080/api/tasks/" + $TASK_ID)

Resultado esperado:

HTTP/1.1 200 OK

El body debe contener:

"title":"P7 tarea manual"

y:

"completed":false


============================================================
7. COMPROBAR EL DATO EN LA INTERFAZ
============================================================

Start-Process "http://localhost:4200"

En el navegador debes observar:

P7 tarea manual

La tarea aparece en Angular aunque fue creada directamente mediante:

POST /api/tasks


============================================================
8. ELIMINAR LA TAREA MANUAL
============================================================

curl.exe -i -X DELETE ("http://localhost:8080/api/tasks/" + $TASK_ID)

Resultado esperado:

HTTP/1.1 204 No Content

Comprueba que ya no existe:

curl.exe -i ("http://localhost:8080/api/tasks/" + $TASK_ID)

Resultado esperado:

HTTP/1.1 404 Not Found

Elimina el archivo temporal:

Remove-Item -Force $REQUEST_FILE


============================================================
9. REVISAR EL TEST INSTRUCTOR
============================================================

Get-Content $INSTRUCTOR

Identifica en el codigo:

request.post()

Prepara el dato mediante API.

page.goto()

Abre la aplicacion.

getByRole('checkbox').check()

Realiza la accion del usuario desde la UI.

request.get()

Verifica mediante API el estado persistido.

request.delete()

Elimina el dato creado por la prueba.


============================================================
10. VALIDAR QUE PLAYWRIGHT RECONOCE LA PRUEBA
============================================================

Set-Location $TEST_AUTOMATION

npx.cmd playwright test "practices/day-03/practice-07/api-ui-integration-instructor.spec.ts" --list

Debes observar:

preparar por API, actuar por UI y verificar por API


============================================================
11. EJECUTAR LA PRUEBA
============================================================

npx.cmd playwright test "practices/day-03/practice-07/api-ui-integration-instructor.spec.ts" --reporter=line

Resultado esperado:

1 passed


============================================================
12. OBSERVAR LA PRUEBA PASO A PASO
============================================================

Ejecuta:

npx.cmd playwright test "practices/day-03/practice-07/api-ui-integration-instructor.spec.ts" --debug

Playwright abrira:

- el navegador;
- Playwright Inspector;
- la prueba detenida para poder avanzar paso a paso.

Utiliza el boton:

Step over

para observar cada accion de la prueba.

Pon especial atencion cuando la prueba:

1. abre Angular;
2. encuentra la tarea creada previamente por API;
3. localiza el checkbox;
4. marca la tarea como completada;
5. verifica visualmente el cambio de estado.

El POST inicial y el GET/DELETE posteriores ocurren mediante API, por lo que no producen una accion visible en el navegador.


============================================================
13. COMPROBAR EL CLEANUP
============================================================

Set-Location $REPO

$TASKS_JSON = curl.exe -sS http://localhost:8080/api/tasks

$TASKS_JSON

$TASKS = @($TASKS_JSON | ConvertFrom-Json)

$P7_TASKS = @($TASKS | Where-Object { $_.title -like "P7 API UI *" })

Write-Host ("P7 tasks remaining: " + $P7_TASKS.Count)

Resultado esperado:

P7 tasks remaining: 0
