============================================================
3. IDENTIFICAR EL ACTOR
============================================================

El Actor representa a la persona o sistema que interactua
con el sistema bajo prueba.

En este ejercicio se crea:

const diego = actorCalled('Diego');

El Actor sera quien ejecute las actividades del escenario.

============================================================
4. IDENTIFICAR LA INTERACTION
============================================================

La Interaction representa una accion concreta.

En esta practica utilizamos:

AddTodoItem

Su responsabilidad es modificar directamente la lista de tareas.

La Interaction realiza:

todoItems.push(...)

Esto representa la accion concreta sobre el sistema.

============================================================
5. IDENTIFICAR LA TASK
============================================================

La Task representa una intencion de negocio.

En esta practica utilizamos:

CreateTodo

Su responsabilidad es expresar:

"crear una tarea"

La Task no modifica directamente los datos.

En su lugar utiliza:

AddTodoItem(title)

De esta manera:

Task

representa la intencion.

Interaction

representa la accion concreta.

============================================================
6. EL ACTOR EJECUTA LA TASK
============================================================

El Actor ejecuta actividades mediante:

attemptsTo()

Ejemplo:

await diego.attemptsTo(
  CreateTodo('Preparar capacitacion'),
);

============================================================
7. IDENTIFICAR LA QUESTION
============================================================

Una Question permite consultar informacion sobre el estado
del sistema.

En esta practica utilizamos:

PendingTodoCount()

La Question filtra las tareas pendientes y devuelve:

pendingItems.length

La Question no modifica el estado.

Solamente consulta informacion.

============================================================
8. EL ACTOR RESPONDE LA QUESTION
============================================================

El Actor puede responder Questions utilizando:

answer()

Ejemplo:

const pendingCount = await diego.answer(
  PendingTodoCount(),
);

El resultado se almacena en:

pendingCount
