============================================================
3. INTERFAZ TASK
============================================================

La interfaz Task define la estructura que debe tener
cada tarea.

interface Task {
  title: string;
  completed: boolean;
}

title debe contener texto.

completed solamente puede contener:

true

o:

false

============================================================
4. COLECCION TIPADA
============================================================

Las tareas se almacenan utilizando:

Task[]

Esto indica que todos los elementos de la coleccion deben
cumplir con la estructura definida por Task.

Ejemplo:

const tasks: Task[] = [
  {
    title: 'Preparar capacitacion',
    completed: false,
  },
];

============================================================
5. FUNCIONES TIPADAS
============================================================

La practica contiene funciones que reciben y devuelven
tipos definidos explicitamente.

Ejemplo:

function getPendingTasks(tasks: Task[]): Task[]

La funcion recibe:

Task[]

y devuelve:

Task[]

Tambien se utiliza:

function countPendingTasks(tasks: Task[]): number

La funcion recibe una coleccion de tareas y devuelve
un numero.

============================================================
6. FILTRAR TAREAS
============================================================

La practica utiliza filter para obtener tareas segun
su estado.

Tareas pendientes:

tasks.filter(task => !task.completed)

Tareas completadas:

tasks.filter(task => task.completed)

RESULTADO:

Las operaciones mantienen objetos de tipo Task.

============================================================
7. CODIGO ASINCRONO
============================================================

La funcion:

async function loadTasks(): Promise<Task[]>

representa una operacion asincrona que devuelve una
coleccion de tareas.

La funcion principal utiliza:

await loadTasks()

Esto permite esperar el resultado antes de continuar.

--moduleResolution node

indica a TypeScript que resuelva las dependencias utilizando
el mecanismo de resolucion de modulos de Node.js.
