============================================================
15. IMPORT Y EXPORT
============================================================

Cuando las responsabilidades se separan en archivos
necesitamos compartirlas.

export

permite exponer una responsabilidad.

Ejemplo:

export const CreateTodo

------------------------------------------------------------

import

permite utilizar una responsabilidad desde otro archivo.

Ejemplo:

import { CreateTodo } from './screenplay/tasks/CreateTodo';
