PASO 1 — REVISAR LA PRIMERA PRUEBA UI
============================================================

La prueba se encuentra en:

Contenido:

// Importamos las funciones test y expect proporcionadas por Playwright Test.
import { test, expect } from '@playwright/test';

// Definimos nuestra primera prueba automatizada de interfaz.
test('crear una tarea desde la interfaz', async ({ page }) => {

  // Abrimos la aplicación To-Do App.
  await page.goto('http://localhost:4200');

  // Localizamos el campo de captura utilizando su etiqueta accesible.
  const taskInput = page.getByLabel('Nueva tarea');

  // Escribimos el nombre de la tarea.
  await taskInput.fill('Preparar capacitación');

  // Localizamos el botón por su rol y por el texto que ve el usuario.
  const createButton = page.getByRole('button', { name: 'Crear tarea' });

  // Hacemos clic para crear la tarea.
  await createButton.click();

  // Localizamos específicamente la tarea que acabamos de crear.
  const createdTask = page.getByText('Preparar capacitación');

  // Verificamos que la nueva tarea aparezca en la interfaz.
  await expect(createdTask).toBeVisible();

  // Localizamos el contador de tareas pendientes.
  const pendingCount = page.getByTestId('pending-count');

  // Verificamos que ahora exista una tarea pendiente.
  await expect(pendingCount).toHaveText('Pendientes: 1');
});

PASO 3 — IDENTIFICAR LAS PARTES PRINCIPALES DE LA PRUEBA
============================================================

NAVEGACIÓN
----------

await page.goto('http://localhost:4200');

Abre la aplicación que será probada.


LOCATOR POR ETIQUETA
--------------------

const taskInput = page.getByLabel('Nueva tarea');

Localiza el campo utilizando información accesible de la interfaz.


INTERACCIÓN
-----------

await taskInput.fill('Preparar capacitación');

Escribe información dentro del campo.


LOCATOR POR ROL
---------------

const createButton = page.getByRole('button', { name: 'Crear tarea' });

Localiza el botón mediante su rol y mediante el nombre que ve el usuario.


INTERACCIÓN
-----------

await createButton.click();

Ejecuta la acción de creación.


LOCATOR POR TEXTO
-----------------

const createdTask = page.getByText('Preparar capacitación');

Localiza específicamente el contenido que esperamos encontrar después de crear la tarea.


ASSERTION
---------

await expect(createdTask).toBeVisible();

Comprueba que la tarea creada aparezca realmente en la interfaz.


LOCATOR POR TEST ID
-------------------

const pendingCount = page.getByTestId('pending-count');

Localiza el contador de tareas pendientes mediante un identificador pensado para automatización.


ASSERTION
---------

await expect(pendingCount).toHaveText('Pendientes: 1');

Comprueba que el estado observable de la aplicación haya cambiado después de crear la tarea.


OBSERVACIÓN
-----------
La prueba no utiliza:

page.waitForTimeout(...)

Playwright espera automáticamente a que las condiciones de las assertions se cumplan dentro del timeout configurado.

Esto evita utilizar esperas fijas arbitrarias.
